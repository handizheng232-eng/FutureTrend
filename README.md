# 中国期货长线趋势研究平台

覆盖中国当前挂牌的 **88 个期货品种**（期货，不含期权）：SHFE 20、INE 5、DCE 23、CZCE 27、CFFEX 8、GFEX 5。

## 页面架构

1. **全市场板块全览**：市场广度、趋势离散度、板块趋势树图和88品种状态扫描；扫描区逐项披露趋势分的组成、权重、标准化与阈值。
2. **长线趋势系统库**：收盘价通道突破、多重均线、MACD、DMI/ADX、BOLL、6/12月均线+月度KST、综合趋势评分，并完整解释综合分的计算原理。
3. **参数实验室**：默认平衡档以季度60日和半年度120日为主轴；另提供偏月度/季度的灵敏档、偏半年度/年度的稳健档。
4. **全市场相对强弱**：商品、股指和国债统一评分；显示趋势强度×过去60日评分变化、强弱排名和全市场明细表。
5. **潜在趋势萌芽**：识别“季度仍震荡或弱趋势、半年度/年度方向已经形成”的跨周期错位，给出透明的0～100观察优先级，而不冒充已校准概率。
6. **单品种价量持仓诊断**：联动展示K线、MA60/MA120、所选系统历史评分、成交量与持仓量，并按60日价涨/价跌与增仓/减仓解释当前阶段。

## 行情口径

- 数据源：新浪期货日K；无需账号或密钥。
- 价格序列：`品种代码 + 0` 主力连续。
- 连续方式：未复权直接拼接，保留换月跳点。
- 字段：开、高、低、收、成交量、持仓量。
- 频率：源数据为日频；12月均线+KST系统由日线聚合为月末收盘后计算。
- 资产范围：商品、股指和国债期货均纳入；低流动性挂牌品种保留并标记日期。

> 主力连续换月价差会影响收益、突破、均线、ATR、MACD和BOLL。当前评分用于趋势研究和横截面比较，不是可直接交易的连续收益。

## 趋势计算原则

- 价格决定趋势方向；成交量与持仓量只作为确认项，不单独反转方向。
- 所有系统得分统一映射至 `-100～100`，用于同一时点横截面排序。
- 平衡档核心窗口为季度约60个交易日、半年度约120个交易日，并以252日年度窗口提供长期背景。
- 相对强弱图横轴为当前系统得分，纵轴为过去60个交易日的系统得分变化。
- 单品种模块用于回放信号与价量持仓的同步变化，不把未复权连续合约计算结果表述为可交易收益回测。
- 综合基础分 = 34%多周期动量 + 24%均线结构 + 16% MACD + 12% RSI + 14% BOLL；多周期动量内部按60/120/252日的20%/30%/50%合成。
- 量仓确认按60日成交量比和60日持仓变化加减分，合计影响上限约24分；确认项不能单独改变由价格确定的方向。
- 趋势萌芽分由长期方向迹象35%、季度暂停25%、压缩15%、边界接近15%、量仓参与10%构成；它不是未来收益概率。
- 默认参数是透明研究基线，不是样本内最优参数；应通过参数邻域、跨市场和样本外检验验证。

## 文件

- `config/universe.csv`：88个挂牌品种、板块和官方链接；
- `refresh_data.py`：抓取、验证、计算和缓存降级；
- `serve.py`：无日志、线程化本地HTTP服务；
- `data/market.json`：浏览器消费的行情快照；
- `assets/trend-engine.js`：七套可参数化趋势评分引擎及趋势萌芽评分；
- `assets/app.js`：全市场聚合、参数联动、相对强弱、萌芽候选和单品种诊断；
- `index.html` + `assets/styles.css`：网页结构与样式。
